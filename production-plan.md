## Production plan: 200 casinos, daily refresh

I would host the static comparison site in S3 behind CloudFront, with an owned domain in Route 53 and an ACM-managed HTTPS certificate. The scrape worker would be an ECS Fargate task started daily by EventBridge, rather than keeping a server running. It would fetch in batches with per-domain rate limits, robots checks, timeouts and backoff; a block or changed layout would stop that source rather than trigger evasive retries. Gemini structured output would extract the terms and validate against a schema. For production I would use a metered API project with budget alerts, not rely on a free-tier quota. Source URL, raw text, fetch time and source-reported effective date would be retained for review.

I would store current offers and their change history in Amazon RDS PostgreSQL. RDS automated backups with a 7-day retention window plus a weekly snapshot copied to a separate account/region would cover recovery. A run table would record each casino's success, changed values and errors so a partial daily run cannot overwrite good data with missing values. The worker would publish a new site JSON only after validation succeeds.

EventBridge would retry transient task-start failures; the task would exit non-zero on a failed run. CloudWatch would retain structured logs and metrics (success count, freshness and field-validation failures), with alarms sent through SNS email if a run fails or data gets stale. I would also alert on meaningful bonus changes for human review.

Rough monthly AWS cost: **$40–100** at this scale for a small database, scheduled compute, static hosting/CDN, logs and backups, plus approximately **$1–10** for a small text-extraction model workload (to be checked against actual token usage); domain registration is about $12–20/year for a typical `.com`. Traffic, model choice, database availability settings and region change the total; a multi-AZ production database can move it above this range. HTTPS is included through ACM; DNS and the annual domain are managed in Route 53.
